# Coding Solutions Repository

Contains solutions to 4 programming problems in both Python and JavaScript.

## Problem List
1. **Calculator Program** - Basic arithmetic operations
2. **Odd Number Series** - Generates odd number sequences
3. **Alternate Series** - Special number sequence generation
4. **Multiples Counter** - Counts multiples in a list

## How to Run
### Python
```bash
python Problem-1.py
python Problem-2.py
python Problem-4.py
```
### JavaScript
```bash
node Problem-3.js
```
